# Clarity Scan

temos que criar uma solucao em inteligencia artificial para solucionar um problema real no mercado, como ja disse anteriormente nooso projeto sera voltada para radiologia odontológica. O objetivo é analisar automaticamente a qualidade das radiografias (panorâmicas e periapicais), identificando se a imagem está adequada para diagnóstico ou se apresenta problemas técnicos, como baixa nitidez, contraste inadequado ou cortes de estruturas importantes.  Além disso, a ferramenta gera um pré-laudo estruturado, auxiliando na padronização e agilização do processo de análise dos exames. A proposta não é substituir o profissional, mas atuar como um suporte inteligente, reduzindo retrabalho, economizando tempo e aumentando a confiabilidade dos exames. falando sobre o prazo, teremos o ano inteiro para desenvolver esse projeto, no qual é uma startup, para apresentar para banca.gostaria de saber se isso é realmente um problema no mercado atual e se voce acha que nossa ideia iria solucionar
